# sakshi-voice-assistant
A Python-based voice assistant using HuggingFace Transformers and Gradio, deployed on Lightning AI.

# Voice Assistant 🎙️

## Features
- Text generation using Flan-T5
- Gradio web interface
- Flask backend for deployment
- Easy to run on Lightning AI
